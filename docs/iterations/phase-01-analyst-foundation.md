# Phase 01 - Analyst Foundation

## Goal

Ship the first meaningful V2 release while keeping the current website live and usable.

## Main Outcome

The portfolio should clearly position Samir as a strong junior `Data Analyst` with measurable impact and clean recruiter-facing communication.

## Scope

- rewrite hero messaging
- rewrite about messaging
- add proof strip / impact metrics
- reorder projects into featured vs supporting
- implement real contact form
- add language persistence and browser auto-detection
- improve mobile spacing and first-screen hierarchy
- add proper favicon and Open Graph image

## Candidate Featured Projects

- Customer Profile Analytics Dashboard
- eSports Analytics Dashboard LATAM
- Grocery Sales BI Dashboard

## Candidate Supporting Projects

- Rice Crop Analytics Platform
- Statistical Analysis: Ping Pong Precision Model
- NASA Space Apps project

## Non-Goals

- no engineering route yet
- no big architectural rework of the app
- no deep modals for every project
- no advanced analytics tooling yet

## Suggested Delivery Order

1. messaging rewrite
2. featured project hierarchy
3. real contact form
4. language behavior
5. trust assets
6. responsive polish

## Definition Of Done

- role is obvious in the hero
- the first 2 minutes of browsing support analyst hiring
- contact flow is real
- mobile feels intentional, not compressed
- social preview and favicon no longer feel unfinished

## Validation

- build passes
- lint passes
- mobile snapshot review
- desktop snapshot review
- recruiter quick-read test: role, impact, featured work, contact all obvious
