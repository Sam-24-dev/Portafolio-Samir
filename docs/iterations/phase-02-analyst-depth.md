# Phase 02 - Analyst Depth

## Goal

Add premium depth without overloading the homepage.

## Main Outcome

The site should offer deeper proof for hiring managers while staying simple for recruiters.

## Scope

- create 1 to 2 analyst case studies
- refine project card content using updated repo evidence
- improve certifications / awards section
- add project filtering only if it remains simple
- improve supporting project archive presentation

## Preferred Project Depth Targets

- Customer Profile Analytics Dashboard
- eSports Analytics Dashboard LATAM

Optional third:
- Grocery Sales BI Dashboard

## Case Study Requirements

Each case study should answer:
- business problem
- dataset and workflow
- tools used
- metrics and result
- what Samir specifically owned
- why it matters

## Non-Goals

- no engineering route yet
- no embedding every external dashboard
- no homepage clutter

## Definition Of Done

- at least two projects feel premium and recruiter-safe
- technical depth exists without hurting homepage scanning
- supporting projects are still visible but clearly lower priority
