# Phase 03 - Conversion And Quality

## Goal

Tighten production quality and reduce credibility gaps.

## Main Outcome

The portfolio should feel polished, trustworthy, and easy to share.

## Scope

- metadata cleanup
- Open Graph and social card validation
- favicon and brand asset cleanup
- image optimization
- PDF weight review
- outdated docs cleanup
- unused dependency cleanup
- accessibility review
- conversion event tracking

## Priority Issues To Resolve

- missing `og-image.jpg`
- broken `/vite.svg` favicon reference in production
- outdated setup docs
- unused `@supabase/supabase-js`
- unused `react-router-dom`
- oversized static assets where avoidable

## Definition Of Done

- link previews look intentional
- portfolio metadata is coherent
- assets are lighter
- repo hygiene is improved
- basic accessibility issues are addressed
