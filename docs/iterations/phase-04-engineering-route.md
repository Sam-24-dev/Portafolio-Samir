# Phase 04 - Engineering Route

## Goal

Activate the second portfolio experience without damaging the analyst-first story.

## Main Outcome

Visitors should be able to discover Samir's engineering depth intentionally, not by accident.

## Scope

- add a secondary `Engineering` route, tab, or context switch
- keep the current analyst-facing homepage as the default
- feature engineering anchor projects
- reuse shared portfolio shell and trust sections

## Engineering Anchor Projects

- Technology Trend Analysis Platform
- RideFare ETL Pipeline

Bridge support:
- Rice Crop Analytics Platform
- eSports Analytics Dashboard LATAM

## Experience Rules

- the default landing view remains analyst-first
- engineering is discoverable but not forced
- avoid duplicated content across both experiences
- shared sections should stay shared where possible

## Definition Of Done

- users can understand both routes quickly
- analyst and engineer positioning no longer conflict
- engineering depth feels intentional and evidence-based
