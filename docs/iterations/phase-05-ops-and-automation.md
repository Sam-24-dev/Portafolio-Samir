# Phase 05 - Ops And Automation

## Goal

Increase confidence and iteration speed once V2 complexity grows.

## Main Outcome

The portfolio becomes easier to maintain and safer to evolve.

## Scope

- add CI checks
- add targeted tests for interactive logic
- add more robust validation for content and metadata if needed
- document release workflow for incremental shipping

## When This Phase Should Start

Only start once:
- the analyst-first V2 is already live
- the engineering route is either planned clearly or partially implemented
- interactive complexity justifies automated checks

## Suggested Quality Targets

- build and lint in CI
- smoke coverage for major interactions if complexity increases
- release checklist for metadata, form, nav, responsive, and key links

## Definition Of Done

- future changes are lower risk
- regressions are easier to catch
- agents can iterate faster with better guardrails
